## 📖 Overview

autoresearch-crypto helps you track and analyze cryptocurrency market data. This tool gathers information from various sources to show you changes in prices and trends. You do not need technical skills to use this software. It performs the heavy lifting of data collection so you can focus on the results you need.

## 🛠️ System requirements

This application runs on Windows computers. Ensure your system meets the following criteria for the best experience:

* Windows 10 or Windows 11 operating system.
* At least 4 gigabytes of memory.
* An active internet connection to download market data.
* A screen resolution of 1280x720 or higher.
* At least 200 megabytes of free space on your hard drive.

## ⚙️ How to use the software

Once the installation finishes, you can open the application from your desktop shortcut. The main window shows a search bar and a list of tracked currencies.

### Adding a cryptocurrency
You can add a coin to your list by typing the name into the search box. Press the enter key to fetch the current statistics. The application logs the price, the daily volume, and the current market capitalization.

### Viewing trends
The software displays data in a table format. Each column represents a metric such as percentage change or total market rank. You can sort these columns by clicking the header at the top of each list.

### Saving your research
If you want to keep records for later, click the "File" menu and select "Export to PDF." This creates a report of the data you gathered during your session.

## 📋 Frequently asked questions

### Does the software store my data online?
No. All data stays on your computer. The software does not transmit your personal search history to any external servers.

### Can I track multiple currencies at once?
Yes. You can add as many coins as you need. The software updates the data every five minutes to ensure you have the latest information.

### Why does the software need an internet connection?
The program must communicate with public financial databases to retrieve live price updates. It cannot fetch data while offline.

### What do I do if the software stops responding?
Close the application and reopen it. If the issue persists, check that your internet connection works. You may also reinstall the application using the same steps from the download section.

### Is this software free to use?
Yes. This is an open-source tool. You can download and run it without any cost or subscription requirements.
